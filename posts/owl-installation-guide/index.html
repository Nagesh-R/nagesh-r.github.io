Installing OWL

Get OWL installed and ready to use in a few simple steps. This guide walks you through downloading the application, configuring your local AI engine and setting up your private workspace.

OWL processes your notes, documents and AI conversations locally. An internet connection is needed initially to download the application and AI models. Once everything is installed, OWL can operate offline.

1. Before you begin

Before installing OWL, make sure your computer meets the following requirements.

System requirements

RequirementDetails
Operating systemmacOS
ProcessorApple Silicon or Intel
ApplicationLatest OWL release
Internet connectionRequired for initial download and model downloads
GPUNot required
Memory (RAM)8 GB (Minimum)

Supported platforms

OWL currently provides packaged installations for:

  • macOS – Apple Silicon (ARM64)
  • macOS – Intel (x64)

Linux and Windows builds are not currently officially packaged.

Optional: Ollama / llama

OWL includes a bundled local AI engine, so installing an external AI runtime is not mandatory.

If you prefer managing your own AI models, you can optionally install Ollama / llma app.

2. Download OWL

Download the latest version of OWL from the official GitHub releases page.

Download OWL – Latest Release

3. Install OWL

Once the download is complete:

  1. Locate the downloaded .dmg file.

  2. Double-click the file to mount the installer.

  3. Drag the OWL application into your Applications folder.

  4. Wait for the copy operation to finish.

  5. Eject the mounted OWL installer.

OWL is now installed on your Mac.

4. First launch

Open your Applications folder and launch OWL.

macOS security warning

The current OWL release is not signed with an Apple Developer certificate. Consequently, macOS Gatekeeper may display the following warning:

“OWL is damaged and can’t be opened.”

This is a Gatekeeper restriction associated with the unsigned downloaded application; it does not necessarily indicate that the application is damaged.

If you downloaded OWL from the official release page and trust the release, follow these steps:

  1. Make sure OWL has been copied into your Applications folder.

  2. Open Terminal.

  3. Execute the following command:

xattr -dr com.apple.quarantine /Applications/OWL.app

  1. Return to your Applications folder.

  2. Open OWL again.

This removes the macOS quarantine attribute from the OWL application. Only do this for a release you trust.

This is a one-time operation. Subsequent in-app updates do not require repeating it.

5. Set up your OWL vault

On your first launch, OWL will guide you through creating your vault.

You will be asked to configure a master passphrase.

The master passphrase protects your encrypted vault and is used to unlock protected content.

Important: Keep your master passphrase safe. OWL uses it to derive the encryption key, and a forgotten passphrase cannot be recovered.

Once the vault is initialized, you can start using your workspace.

6. Configure your local AI assistant

OWL supports two local AI configurations:

Bundled AI engine (llama.cpp)

External Ollama / llama provider

Option A: Use the bundled AI engine (recommended for beginners)

OWL includes a bundled AI engine, so you don’t need to install another application.

  1. Open OWL.

  2. Navigate to Settings → Local AI.

  3. Select the bundled AI provider.

  4. Choose an available AI model.

  5. Allow OWL to download the model.

  6. Wait until the model is ready.

The default model is designed to be small and fast. You can select larger models if your computer has sufficient memory and storage.

Option B: Use Ollama

If you already use Ollama or prefer managing your own models:

  1. Download and install Ollama.

  2. Download the model you want to use.

  3. Open OWL.

  4. Navigate to Settings → Local AI.

  5. Select the Ollama provider.

  6. Choose one of your locally available models.

OWL will manage starting and stopping the Ollama process.

7. Enable semantic search

OWL supports hybrid search, combining keyword-based and semantic search to retrieve relevant information from your notes.

Keyword search works without additional model downloads.

To enable semantic search:

  1. Open Settings → Notes Q&A.

  2. Download the embedding model.

  3. Select Rebuild semantic index.

  4. Wait for the indexing process to complete.

Once indexing is complete, OWL can use semantic search when answering questions about your notes.

Note: Encrypted notes are never indexed or supplied to the AI in plaintext.

8. Improve search with re-ranking

Re-ranking improves search relevance by evaluating the initial search results and ordering them according to how closely they match your query.

OWL first retrieves relevant results using its search mechanisms. The re-ranking model then evaluates those results to improve their relevance before they are presented.

To enable semantic search:

  1. Open Settings → Search.

  2. Download the re-ranker model.

  3. Enable Reranking.

9. Troubleshooting

OWL is damaged and can’t be opened

This is a macOS Gatekeeper issue related to the unsigned application.

Follow the instructions in First launch → macOS security warning.

AI model download fails

  • Check your internet connection.

  • Ensure sufficient disk space is available.

  • Retry the download from Settings → Local AI.

AI assistant is not responding

  • Verify that the selected model has finished downloading.

  • Check that the selected AI provider is running.

  • If using Ollama, ensure it is installed and available.

Semantic search returns no results

  • Verify that the embedding model has been downloaded.

  • Rebuild the semantic index.

  • Confirm that your notes contain searchable content.

10. What’s next?

Now that OWL is installed, explore the features available in your personal workspace.

  • Notes: Create, organise and manage your Markdown notes.

  • AI Assistant: Chat with your notes and documents.

  • Documents: Import PDFs and ask questions about their contents.

  • Tasks & Projects: Organise your work and track progress.

  • Time Tracking: Monitor time spent on tasks and meetings.

  • Jira Integration: Connect your Jira projects and manage worklogs.

Explore the OWL documentation to get the most out of your personal workspace.

Need help?

If you encounter an issue during installation, visit the OWL GitHub repository and open an issue with details about your macOS version and the problem you’re experiencing.
